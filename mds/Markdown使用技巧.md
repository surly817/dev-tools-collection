# Markdown 基础语法

- [ ] 快速选取当前行、删除当前行、切换光标至上下行、将本行/框选内容向上向下移动 快捷操作待确认
- [ ] 快速切换上下文件
- [ ] 快速跳转至文件某一位置/自动移动至上次编辑地址





```shell
# 实测常用便利命令
快速标题
	command + 1～6
快速加粗
	command + b
快速斜体
	command + i
源代码模式
	command + /
折叠侧边栏
	command + shift + l
快速代码块
	command + option + c
大纲/文件夹侧边栏切换[按键不舒适]
	control + command + 1/3
专注模式[仅高亮当前输入内容]
	F8
打字机模式[回车自动换行且画面向上移动]
	F9
```





``` makefile
1. 标题
  \# ～ ####### 1～6级标题
2. 列表
  无序列表：用 -、* 或 +
  有序列表：数字 + .
3. 代码块
  行内代码：用反引号 ` 包裹
  多行代码块：用三个反引号 ``` + 语言标识
4. 链接与图片
  链接：[显示文本](链接地址)
  图片：![图片描述](图片地址)
5. 文本格式
  加粗：**文本** 或 __文本__ 
  斜体：*文本* 或 _文本_
  删除线：~~文本~~
6. 引用
  语法：> 表示引用
7. 表格
  语法：用 | 分隔列，- 分隔表头与内容
8. 分割线
  语法：三个及以上 ---、*** 或 ___
9.注释
  <!-- 注释内容 -->
```

``` makefile
# 快捷键
插入表格：option + command + T
取消自动序号[数字或·] ”按两次回车键“，或按 command + [
插入超链接：command + K
文本加粗：command + B
文本斜体：command + I
文本下划线：command + U
删除线：control + shift +     `（tab键上面的那个键）
标题：command + 1 ；command + 2 ……；command + 7
段落（正文）：command + 0
水平分割线：3个或3个以上的 -
代码模块：option + command + C
公式模块：option + command + B
单个代码：control +     ` （tab键上面的那个键）
插入图片：control + command + I
注释：control + -
```
